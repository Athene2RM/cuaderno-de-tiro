# Cuaderno de tiro

Webapp instalable (PWA), personal y sin conexión, para registrar sesiones de tiro con aire comprimido y analizar la precisión. Ver `SPEC.md`.

```
npm install
npm run dev    # abre la URL de red en el móvil, en la misma wifi
npm test
```

Los datos se guardan solo en el navegador del móvil (IndexedDB). Exporta copias de seguridad desde Equipo › Copias de seguridad.
